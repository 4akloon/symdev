## 1. Goal

On this Linux edit+build host, `symdev new <name> --target nokia-e52` writes a project tree that `symdev build` and `symdev package` can consume without the human copying sources by hand.

`symdev deploy` in this slice only prints the absolute path of an existing `.sisx`. No memory-card copy, no Bluetooth OBEX, no SSH, no E52 claim.

## 4. `symdev new`

### 4.1 CLI

Unchanged clap: `symdev new <name> --target <device> [--lang cpp]`.

`--target` required, only `nokia-e52`. `--lang` default `cpp`, only `cpp`. `name` already validated as `[A-Za-z][A-Za-z0-9_]*`.

After clap accepts: create the tree (no longer `not implemented`). Do **not** read an existing `symdev.toml` in cwd. Do **not** spawn GCC, Wine, or SIS tools.

Success: print the absolute path of `./<name>`, exit 0.

### 4.2 Tree for `symdev new hello` from an empty cwd

```
hello/
  symdev.toml
  group/bld.inf
  group/hello.mmp
  src/hello.cpp
  src/hello.h
```

For a different `<name>`, only the directory name, `symdev.toml` `[package].name`, `group/<name>.mmp`, `bld.inf` MMP filename, and MMP `TARGET <name>.exe` change. `src/hello.cpp` and `src/hello.h` stay those names.

### 4.3 `symdev.toml`

Same tables as the north-star hello example, plus a generated `uid3`:

```toml
[package]
name = "hello"
version = "0.1.0"

[target]
device = "nokia-e52"

[language]
name = "cpp"

[symbian]
uid3 = "0xef9f2cab"
capabilities = []
vendor = "symdev"

[signing]
mode = "self-signed"
```

`uid3` spelling: `0x` + 8 lowercase hex digits (manifest accepts mixed case; writers use lowercase to match M2 `.pkg` hex).

### 4.4 uid3 algorithm

32-bit FNV-1a over the UTF-8 bytes of `name`:

- offset basis `2166136261` (`0x811c9dc5`)
- prime `16777619` (`0x01000193`)
- for each byte `b`: `h ^= b as u32`; `h = h.wrapping_mul(16777619)`
- `uid3 = 0xE0000000 | (h & 0x0FFFFFFF)`

Pinned: `name = "hello"` → `0xef9f2cab`. Always in the E-range; never the protected or A-range.

### 4.5 `group/bld.inf`

Omit `PRJ_PLATFORMS` (parser default = ARMV5 UREL GCCE; experiment 12: 125 example `bld.inf` omit the directive). No `#ifdef`. LF line endings.

```
PRJ_MMPFILES
hello.mmp
```

Substitute `hello.mmp` → `<name>.mmp`.

### 4.6 `group/<name>.mmp`

Only directives on the M1 support list that the Wave 0 driver actually reads (`TARGET`, `TARGETTYPE`, `SOURCEPATH`, `SOURCE`):

```
TARGET hello.exe
TARGETTYPE EXE
SOURCEPATH ../src
SOURCE hello.cpp
```

`SOURCEPATH` is POSIX `../src` so `resolve_source` does `mmp_dir.join("../src").join("hello.cpp")` → `src/hello.cpp`. Do not use Windows backslashes (on Linux they are a filename character).

No `UID`, `LIBRARY`, `SYSTEMINCLUDE`, `START RESOURCE`. M1 `GcceBuild` uses recorded compile/link argv, not MMP library lines.

### 4.7 `src/hello.cpp` and `src/hello.h`

Byte-for-byte copies of the experiment 5 public-domain Carbide listing (including the provenance comment that names the blog URL). Do not substitute `<name>` inside them.

### 4.8 Errors

| Case | stderr | exit |
|---|---|---|
| `./<name>` already exists | `error: directory \`<name>\` already exists` | 1 |
| clap rejects name / target / lang | clap usage | 2 |
| IO while writing | `error: <io>` | 1 |

Create files only after the existence check. If a later write fails, do not promise rollback in this slice (leave a partial tree); still return the IO error.

## 5. `symdev deploy` (print-path)

Load `./symdev.toml` (same missing/invalid behaviour as `build` / `package`).

Then look for `./build/<package.name>.sisx`.

- Exists: print its absolute path, exit 0.
- Missing: `error: SISX not found: build/<name>.sisx (run symdev package)`, exit 1.

Do not require `uid3`, `SYMDEV_EPOCROOT`, or `SYMDEV_SIGN_PASSWORD`. Do not spawn Wine. Do not copy files.

## 7. Testing

Default `cargo test` does not spawn Wine and does not need the SDK tree.

Required CLI tests:

- `new hello --target nokia-e52` in an empty temp dir creates the tree in §4.2; `src/hello.cpp` matches the template bytes; toml `uid3` is `0xef9f2cab`; stdout is the absolute `hello` path; exit 0.
- Second `new hello` in the same parent fails with the exists error; the first tree is unchanged.
- `new` still does not read a bogus `symdev.toml` in cwd (existing `new_does_not_read_toml`).
- `deploy` with a valid toml and no sisx → SISX not found (not `not implemented`).
- `deploy` with a dummy `build/<name>.sisx` → prints that file’s absolute path, exit 0.

`build` / `package` tests stay unchanged. `new_not_implemented_creates_no_files` is replaced: `new` **does** create files on success; keep a test that a **failed** `new` (exists, or invalid clap) creates no extra files.
