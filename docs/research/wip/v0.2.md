## Gaps (symdev 0.2.0)

1. `symdev new --lang rust` writes absolute `rust-sdk/<ver>` paths (spec §12 known gap).
2. Package indexes are unsigned (spec §11).
3. A developer's own `RUSTFLAGS` replaces the libcalls build's `build.rustflags`.
4. A server that sends headers then stalls the body is bounded only by the 1 h limit.
5. `RustSdkPackage::REQUIRED` does not check that the SDK workspace's examples are present.
Not fixable without the owner: custom domain for the public bucket; container acceptance
(no docker/podman without sudo).

  linker script, local `.strtab`-padding fix of SDK DSOs, TARGET2→ABS32 rewrite, 5 elf2e32
  rules; EKA2L1 behaviour identical; cost +2–8 % (20-byte vs 8-byte import stubs).
- Owner: (1) prebuilt shims go in the **public** bucket (inside/next to `rust-sdk`), (2) the
  five elf2e32 rules for lld ELFs are **accepted, labelled** "derived from the ARM ABI and
  lld's documented behaviour, verified in EKA2L1" — a narrow, recorded exception to the
  "not observed → error" rule, applying only to lld-produced ELFs; (3) **8-byte stubs first**:
  rust-lld stays opt-in, GNU ld the default, until the size matches GNU's.
- Starts after G1 lands (both touch the Rust build driver). Packages CI will need the private
  source's reader key to compile the shims against the SDK headers (owner step).
