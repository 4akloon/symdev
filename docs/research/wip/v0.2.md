## G2: signed package indexes (branch `index-signing`, both repositories)

Design (lead, 2026-10-03): the signature is the first line of `index.toml`,
`# symdev-signature: ed25519 <base64 of 64 bytes>\n`, over exactly the bytes after it (0.1.0
clients read it as a TOML comment). Ed25519 via `ed25519-dalek` 2; the project key's seed in
the owner's `~/.config/symdev/keys.env` as `PUBLISH_SIGNING_KEY`, its public key embedded in
symdev (`TrustedKeys`, a list for rotation). Built-in source: signature mandatory. Configured
source: `key = "builtin" | "<base64 public key>"` makes it mandatory; absent = as 0.1.0.
`publish` signs every index it writes; `publish sign-index --bucket …` re-signs the live ones.
install.sh verifies with OpenSSL 3 (`pkeyutl -verify -rawin`), warns without it.
Worktrees: `~/worktrees/symdev/index-signing`, `~/worktrees/symdev-packages/index-signing`.

Project key (2026-10-03): generated with `openssl genpkey -algorithm ed25519`; seed appended to
`~/.config/symdev/keys.env` as `PUBLISH_SIGNING_KEY` (mode 600, checked by rebuilding the
key from it); private PEM/DER shredded; `~/src/index-key/public.{der,pem}` kept. Public key
(raw, base64) `C1yh60B72Qa4YE4rZOgoPJZmTYKbh/uzHjupoVwqfLU=`, fingerprint (sha256 of the
32 raw bytes) `bdf5345cc3ca8c30661dbc53b2cbd16983d081bf26913d0c3ebe7480ca334d44`.

Decisions beyond the lead's design (recorded in spec §14):
- The publisher extends only an index whose signature verifies (built-in keys + its own key);
  an unsigned one is refused by an upload, warned about in a dry run, and accepted only by
  `sign-index`. Reason: otherwise the next CI publish signs what a leaked R2 key wrote.
- install.sh with OpenSSL 3: an unsigned index is a hard error too (stripping the line would
  otherwise bypass the check). Without OpenSSL 3: warning, for signed and unsigned alike.
- `sign-index` has `--dry-run` (prints the signed index) and skips the upload when the bytes
  would not change; it signs the existing body as is (no re-serialisation).
- Owner order: secret → `sign-index` both buckets → only then the new install.sh and 0.2.0.
- `key = "builtin"` must not go into the owner's sources.toml before 0.2.0 is installed:
  0.1.0's parser has `deny_unknown_fields`.
